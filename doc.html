Glitches you might run into

speed, this glitch is from the computer's velocity, found in hard mode
if you move to fast, the green figure teleports faster between frame causing him to miss the target, like how you
can't catch a baseball with slow reflects, little green has issues too
swing teleportation, found in easy mode or any mode, this happens when you jump and a swing is overlapping with your area, you catch that swing
this can be fixed by a manual catch mode where the user choose when to catch this isn't really a problem.
performance issue, because the physics requires javascript, in a web browser, the preformance isn't always good. The game utilizes binary trees amd efficant search for large preformance breakers, but still, the physics requires heavy lifting. this can be fixed by gifs of swings and videos instead of caculating physics, but this can be memory intensive.
